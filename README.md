## 📖 О проекте

**shark24** — это утилита для командной строки, написанная на чистом C. Она создана для тех, кто устал от сложных флагов `grep` и `find` и хочет простой, быстрый и понятный инструмент для поиска строк в файлах.

**Главная цель:** Сделать поиск по коду максимально быстрым и удобным. Никаких лишних зависимостей, только чистый C и системные вызовы POSIX.

## 🚀 Использование (Usage)

Синтаксис:
`shark24 [options] <keyword> <directory>`

### Флаги:

*   **`-i`** — Игнорировать регистр (искать `MAIN`, `main` и `Main` одинаково).
*   **`-n`** — Показывать номера строк (выводит `путь:номер_строки: текст`).
*   **`-l`** — Выводить только имена файлов (без самих строк).
*   **`-e <папка>`** — Исключить указанную папку из поиска.
*   **`--version`** или **`-v`** — Показать версию программы.

### Примеры:

`./shark24 -n "main" src/`
`./shark24 -i -e "build" "TODO" .`
`./shark24 -l "int" src/`

## ✨ Особенности (Features)

- [x] **Простой синтаксис:** `shark24 "word" path/` — и всё работает.
- [x] **Рекурсивный обход:** Автоматически заходит во все подпапки.
- [x] **Цветной вывод:** Подсвечивает путь к файлу и номер строки.
- [x] **Защита от бинарников:** Игнорирует `.o` файлы и бинарные данные.
- [x] **Комбинирование флагов:** Можно использовать `-i`, `-n`, `-l` и `-e` одновременно.

## 🚀 Установка

1. Клонируй репозиторий:
   `git clone https://github.com/QeZzhi/shark24.git`
   `cd shark24`
2. Сделай скрипт установки исполняемым:
   `chmod +x install.sh`
3. Запусти установку (потребуются права администратора):
   `sudo ./install.sh`

После этого утилита будет доступна глобально. Проверь работу:
`shark24 --version`
